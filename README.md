# 💨 Dead Smoke Store Bot

Telegram-бот магазина вейпов: каталог, корзина, реферальная система,
промокоды, админ-панель, статистика, рассылка.

## Возможности

- 📂 Плоский каталог из 7 разделов
- 🛒 Корзина с поддержкой 2 промокодов (сумма + процент)
- 👑 Админ-панель: добавление / редактирование / удаление товаров
- 🎁 Реферальная система: 15% от первой покупки реферала
- 🏆 Акция: за каждые 10 **купивших** рефералов — промокод на −10%
- 📊 Статистика: выручка, заказы, топ-товары
- 📢 Рассылка всем пользователям
- 🎫 Ручные промокоды от админа (fixed / percent)
- 📜 История заказов и профиль пользователя
